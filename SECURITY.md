# Security policy

This codebase is a **release candidate**, not a third-party security-certified service. Read [Security architecture](docs/SECURITY.md), [Implementation audit](docs/IMPLEMENTATION_AUDIT.md) and [Operations runbook](docs/OPERATIONS.md) before deployment.

Report potential vulnerabilities privately through GitHub Security Advisories for this repository or contact its maintainer. Include a minimal reproduction and the affected version. Do not disclose customer data, access tokens or keys in public issue threads.

Security guarantees require correct deployment-level identity, TLS, network controls, encryption and backups. The code does not independently provide all of these services.
