# Preserved original source (October 4, 2026)

This directory preserves the original project code, tests, infrastructure manifests and short architecture documents. A byte-for-byte copy of the user-provided original archive is included as [`original-source.zip`](original-source.zip), so no original source file is lost during this upgrade.

The legacy Postgres/FastAPI prototype is **not** the executable v2 default and its Dockerfile/Compose/pyproject are retained for reference. Its detailed README is at `../docs/ORIGINAL_README.md`. The v2 code is under `../src/context_fabric/`, the root `README.md` explains how to run it, and `/docs/CAPABILITIES.md` distinguishes working functionality from architectural intentions.
